Self-Check

Sanity tests for the data behind the tools.

What this is

Most of the bugs I've had in these tools weren't crashes – they were a number quietly coming out wrong. A dropped digit, a monthly rate sitting where an annual one belongs, a column shifted by one. This page loads every config file the tools depend on and checks the boring invariants that should always hold, so that sort of thing turns into a red banner instead of a plausible-looking salary figure in someone's offer letter.

What it can't do: it has no idea what the real UCOP scales say. It only knows what a salary scale should look like – increasing, sensibly spaced, in a believable range. A number that's wrong but plausible will sail straight through. Checking against the source PDFs is still a manual job.
