Roster Parser

How to Use
  1. Grab a Class Roster from SIS.
  2. Click 'Choose File' and select your CSV, XLSX, or XLS roster file.
  3. The tool will automatically process the file in your browser.
  4. Use the Report Builder to pick your columns and filter courses (or don't – the default matches the classic output).
  5. A preview of your report will appear below.
  6. Click 'Export as CSV' to download the results.
