# ls-bluecluster-apgrad-tools

The intention of these little tools is to (a) provide administrative staff working in the academic personnel spaces with easily-referenced calculators to aid in faculty and student advising, while (b) also making the same tools those staff use accessible to faculty in a "non-actionable" form, so that they are able to play with live scenarios and to some extent self-advise. 
# summercomp.html
This little calculator allows users to enter an annual salary from which point it derives a maximum available summer compensation. Users can then play with different summer-research compensation scenarios by activating the different months and playing with the FTE within. It is optimized for inclusion in SiteFarm pages via iFrame. 
# sabbatical.html
This calculator allows users to enter a sabbatical credit total and an annual salary, from which point they can activate sabbatical for Fall, Winter, and Spring Quarters, play with salary level and residency, and see the impact on their sabbatical credit usage and total salary. It is optimized for inclusion in SiteFarm pages via iFrame. 
# studentemployment.html
This calculator allows users to create an "employment schedule" for graduate student employees and display the costs associated. It should be used with caution for the time being as it is not currently splitting tuition/fees and health insurance costs for multiple appointments in the same quarter, nor is it adding fee remission to reader/tutor appointments once FTE exceeds 110. Once that's in, further improvements (e.g. support for work-study calculations) will follow.
